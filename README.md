# 🚗 نظام إدارة مكتب إيجار السيارات

نظام متكامل لإدارة مكتب تأجير السيارات، يتيح إدارة أسطول السيارات، إنشاء عقود الإيجار، متابعة حالة كل سيارة، وطباعة العقود بشكل احترافي.

---

## 📌 نبذة عن النظام

يوفر النظام حلولاً شاملة لمكاتب إيجار السيارات، حيث يمكن من خلاله:

- إدارة كاملة لأسطول السيارات (إضافة، تعديل، حذف، عرض).
- إنشاء عقود إيجار رسمية مع بيانات المستأجر والسيارة.
- حساب تلقائي لتكلفة الإيجار حسب عدد الأيام والسعر اليومي.
- متابعة حالة كل سيارة (متاحة / مؤجرة / تحت الصيانة).
- طباعة العقود وتوثيقها.
- لوحة تحكم بإحصائيات فورية.

---

## ✨ المميزات

### 🚙 إدارة السيارات
- إضافة سيارة جديدة (اللوحة، الماركة، الموديل، السنة، اللون، السعر اليومي).
- عرض قائمة السيارات مع حالتها الحالية.
- عرض تفاصيل كل سيارة وسجل عقودها.
- حذف سيارة (مع منع الحذف إذا كانت مرتبطة بعقود نشطة).

### 📝 إدارة العقود
- إنشاء عقد إيجار جديد برقم عقد فريد تلقائياً.
- تسجيل بيانات المستأجر (الاسم، الهوية، الجوال، العنوان).
- تحديد تاريخ البداية والنهاية وحساب عدد الأيام تلقائياً.
- حساب الإجمالي تلقائياً حسب السعر اليومي.
- تسجيل مبلغ التأمين.
- إغلاق العقد وتحرير السيارة تلقائياً.
- طباعة العقد بصيغة رسمية موقعة.

### 📊 لوحة التحكم
- إجمالي عدد السيارات.
- عدد السيارات المتاحة.
- عدد السيارات المؤجرة.
- عدد العقود النشطة.
